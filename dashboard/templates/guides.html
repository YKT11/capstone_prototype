Hands-on local lab guides

You perform every exercise yourself. These are real Kali tools and methods, restricted to 127.0.0.1 / local DVWA inside this isolated VM. Never substitute another IP address, hostname, or network.

Before each exercise

  1. Confirm DVWA is available at http://127.0.0.1/DVWA and its security level is low.
  2. Record only activity you create in this VM.
  3. After the exercise, run python lab/collect_logs.py, python processing/build_dataset.py, and python detection/train.py.

1. Normal baseline

Log in to DVWA as admin / password. Browse the home page, instructions, and a few vulnerability pages normally. This creates Low-risk baseline web requests.

2. Local reconnaissance and path enumeration

First inspect the local web service:

nmap -sV -p 80 127.0.0.1

Then enumerate paths against local DVWA only:

gobuster dir -u http://127.0.0.1/DVWA/ -w /usr/share/wordlists/dirb/common.txt -q

Expected evidence: rapid requests to many paths, including 404 responses. This should become Medium-risk scanning activity.

3. Brute-force behavior

In DVWA, open Vulnerabilities → Brute Force. Submit the username admin with deliberately incorrect passwords at least six times in under one minute. Do not use these credentials or methods anywhere except this local DVWA page.

Expected evidence: repeated requests to the Brute Force module. This should become a High-risk brute-force alert.

4. SQL injection behavior

In DVWA, open Vulnerabilities → SQL Injection. Enter this educational test input into the ID field:

' OR '1'='1

Expected evidence: a request containing an SQLi-like pattern. This should become a High-risk SQL-injection alert.
